拉链法 ASL 计算公式与步骤

计算公式：
ASL成功 =
∑ (每个键的链表深度)当前插入的关键字个数 (n)
元素 key 初始 Hash H(key) 所处链表位置 (1-based) 比较次数
计算公式：
ASL失败 =
∑ (对应散列地址下的链表长度)参与计算的散列地址个数 (divisor)
考研 408 说明：对于 H(key) = key % p 的情况，查找失败的初始散列位置只能落在 [0, p-1] 中。 因此，只累计 slots [0, p-1] 的链表长度，除数 divisor 为 p。
如果是传统教材定义，则累计 slots [0, m-1] 的长度，除数 divisor 为表长 m。

线性探测法 ASL 计算公式与步骤

计算公式：
ASL成功 =
∑ (每个键插入时的探测次数)当前插入的关键字个数 (n)
元素 key 初始 Hash 最终插入槽位 探测比较路径 探测次数
计算公式：
ASL失败 =
∑ (从初始地址探测到空槽的比较次数)参与计算的散列地址个数 (divisor)
算法解析：对于每个可能的初始哈希地址，在查找一个表中不存在的元素时，从该地址出发线性向后探测，直到碰见第一个空槽（Null）方能确认查找失败。该过程经历的探测节点数（包括最后的空槽）即为该地址的失败比较次数。
初始 Hash 线性探测路径 (直到空槽) 探测比较次数
